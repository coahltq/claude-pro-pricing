## $20 买到的到底是什么

官方对 Pro 权益的表述只有三条：比 Free 每次会话更多用量、高峰期优先访问、新功能抢先体验。听起来笼统，实际限制写在帮助文档里。

**两条限额同时生效。** 一条是滚动的 5 小时窗口，另一条是跨所有模型的每周上限。每周上限在账号被分配的固定时间重置，重置的星期和时刻不随你开始使用的时间或订阅开始时间改变，每个周期发放完整额度。下次重置时间可以在 Settings > Usage 里看到。

**所有入口共用同一份额度。** 网页、桌面端、手机 App、Claude Code 消耗的是同一个池子。官方 FAQ 的原话是 Claude Code 包含在所有付费方案中，并"与方案其余部分共用同一用量限额"。这意味着你在终端里跑一段长任务，占用的就是你聊天时的那份额度。一次长长的终端会话，和几十轮对话，扣的是同一笔账。

**用完了可以继续，但要另外付钱。** 在 Settings > Usage 里开启 usage credits 后，超出限额的请求会按标准 API 价自动转为按量计费，费用与订阅费分开出账。不开就等重置。

**Pro 不含 API。** 官方写得很直接：Pro 方案不包含通过 Claude Console 使用的 API 用量，聊天订阅和 API 计费是两套账。Max 每月附带的 $100 或 $200 API 额度也只能在 API 平台花，抵不了聊天和 Claude Code 的用量，也抵不了 usage credits。

官方同时保留了按容量追加限制的权利，并明确不保证服务不间断。所以按"无限使用"来预期会失望，按"一段时间内的高频使用"来预期比较接近实际。

## 常见问题

**Pro 包含 API 吗？**
不包含。Pro 只是聊天产品的订阅，Claude Console 的 API 用量单独计费。Max 每月附带的 API 额度也仅在 API 平台有效。

**Pro 有免费试用吗？**
据核对的结账流程，没有免费试用入口。官方偶尔会有限时促销，但明确表示不提供常设折扣，客服也无法发放一次性优惠码。

**能随时取消吗？**
可以，权益保留到已付费周期结束。在网页端到设置里的账单页取消；通过 App 内订阅的，需要在 Apple 或 Google 账户里取消，并且至少提前 24 小时操作，否则会进入下一期。

**年付中途不用了能退吗？**
取消和退款的具体规则以官方账单帮助文档为准，本文不代述天数。能确定的是年付一次性扣款 $200，中途取消不会把剩余月份折算成现金退回。

**学生有折扣吗？**
没有。官方写明不为个人套餐（Pro、Max）提供标准折扣价，学生同样是 $20/月。部分高校会为全校统一采购，那属于 Education 方案，官方未公开标价。

**手机上和网页上价格一样吗？**
不一样。只有 Pro 月付在美国区两处都是 $20.00，Pro 年付在 App Store 是 $214.99（网页 $200），Max 5x 是 $124.99（网页 $100），Max 20x 是 $249.99（网页 $200）。
